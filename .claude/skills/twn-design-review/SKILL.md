# TWN design review

Read docs/product-direction.md and current design files before visual work.

1. Identify the user goal, approved imagery and brand constraints. No fabricated event photos, reviews or awards.
2. Produce an explicit visual direction (typography, composition, hierarchy, color, photography crop, spacing and motion intent). Avoid generic hero + cards templates, decoration-only animation, tiny type and low contrast.
3. Use authentic licensed assets. Mark placeholders visibly as unapproved. Avoid AI-generated documentary-looking events.
4. Implement semantic structure and accessible interactions; keyboard/hover/focus/touch and screen reader behavior all matter.
5. Respect reduced motion and responsive performance; use GSAP only where CSS/native animation is insufficient.
6. Run build, automated a11y/performance checks where available, and inspect actual desktop and narrow/mobile screenshots. Report precise evidence; do not call a page visually approved without owner review.
7. Critique and refine in one focused pass; do not replace the established design system without a reason.

When available, use the upstream Impeccable plugin for targeted critique/audit/polish. This repository-specific skill does not replace its verified installation.
