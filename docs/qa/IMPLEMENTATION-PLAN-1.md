## One signature moment: “Your celebration, unfolding”

Keep the existing invitation idea and refine it into a single, brief opening of the homepage's arch/invitation frame around a real celebration photograph. Use a restrained SVG floral line and a soft gold accent; preserve the current type and regional voice. The image, readable headline and enquiry action are present from first paint. The flourish completes within approximately **700–900ms**, never gates input or reading, does not replay on every in-page interaction, and has a skip/disable route if an intro is shown. No fullscreen splash, WebGL scene, scroll lock or extra video download is required.

Reduced motion: display the fully open composition with an optional short opacity change; Save-Data/low-capability fallback is the finished static poster. This is a proposed direction, not an implemented effect or measured performance result. The actual hero must still meet D2 once measured.

Exactly three micro-delights:

1. **Compose your celebration:** the existing planner's live, nonpersonal summary gains one restrained state change on a committed choice, with stable focus and reduced-motion treatment.
2. **Real-work mood board:** category filtering and optional shared-image transition for approved gallery material; keyboard/click/touch equivalent, no drag-only or hover-only content. Important images remain accessible without carousel navigation.
3. **Gold accent on a meaningful action:** one small finite gold/petal response to an actual explicit user action, such as copying planning choices. No ambient continuous particle field; no “sent” celebration for a contact-link click. Static confirmation carries the same meaning.

All other animation must serve navigation, state or comprehension and earn its byte/time cost. No extra signature, cursor gimmick or recurring marquee.
